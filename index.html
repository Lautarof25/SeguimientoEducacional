¿Qué es una página web?

Una página web es un documento que podemos visualizar desde un navegador. Está construida con tecnologías como HTML, CSS y JavaScript.

Idea clave HTML define la estructura, CSS se encarga del diseño y JavaScript agrega interacción.

En las próximas lecciones vas a aprender a utilizar estas tecnologías para construir tu propio proyecto.
